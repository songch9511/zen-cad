# Sourcing Checklist

- [ ] Standard parts identified
- [ ] Milestone maturity recorded as `concept`, `layout`, or `final`
- [ ] Part RAG/catalog queries recorded
- [ ] Datasheet/source URLs captured
- [ ] Supplier/manufacturer and exact SKU recorded
- [ ] Cached STEP/STP path recorded and file exists
- [ ] `status: source_locked` set only after source URL, datasheet, STEP/STP, and critical dimensions are verified
- [ ] Proxy parts explicitly set `status: proxy_only` and `completion_eligible: false`
- [ ] Concept/layout proxy use is recorded as non-final evidence
- [ ] Geometry match separated from rating verification
