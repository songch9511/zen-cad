# Zen CAD Plugin

This plugin bundles the supported Zen CAD skill set for agent installs while
keeping the root `skills/`, `tools/`, `schemas/`, and `registry/` directories
as the development source of truth.

Codex consumes `.codex-plugin/plugin.json`. Claude Code consumes
`.claude-plugin/plugin.json`.

Installed skills:

- `cad-spec`
- `assembly-layout`
- `interface-signatures`
- `cad-handoff`
