# Source STEP Parts

## Purpose

`/source-step-parts` is the sourcing and STEP retrieval skill for Zen CAD. Use it before final CAD generation whenever a milestone contains standard, catalog, configurable, or source-first parts.

This skill turns candidate part research into `02_parts/selected_parts_manifest.json`, cached STEP/STP paths, rating evidence, and source-lock blockers. It prevents `/spec-to-cad` from generating lookalike standard parts as final evidence.

## Use This Skill When

Use this skill for:

- screws, nuts, washers, threaded inserts, pins, clips, bearings, bushings, motors, servos, sensors, connectors, belts, pulleys, rails, guide rods, springs, O-rings, seals, fans, hinges, brackets, and other catalog parts;
- semi-standard configurable parts such as extrusions, shafts, standoffs, panels, gears, couplers, and springs;
- any part classified as `off_the_shelf` or source-first `semi_standard_configurable`;
- any final/release claim that depends on supplier geometry, datasheets, ratings, or procurement identity.

Do not use this skill to design project-specific housings, plates, links, fixtures, adapters, or assembly glue. Those belong in `/spec-to-cad`.

## Root and Artifact Contract

Resolve the Zen CAD root and active milestone first. Use:

```text
milestones/<id>/02_parts/part_classification_table.md
milestones/<id>/02_parts/selected_parts_manifest.json
milestones/<id>/02_parts/normalized_step_metadata.json
milestones/<id>/01_research/research_log.md
```

Cache downloaded or copied CAD files under the active milestone, normally:

```text
milestones/<id>/02_parts/step/<part_id>.step
milestones/<id>/02_parts/datasheets/<part_id>.<ext>
```

If the source forbids caching, record the access limitation and source URL. Do not pretend the file is cached.

## Source Priority

Prefer sources in this order:

1. Manufacturer or official distributor CAD/datasheet pages.
2. Supplier catalog pages with explicit manufacturer and part number.
3. Standards-backed component libraries with traceable metadata.
4. Configurable CAD generated by a supplier configurator.
5. Internal approved libraries or prior milestone caches.
6. Proxy/envelope geometry for concept/layout only.

`step.parts`, manufacturer CAD pages, supplier CAD pages, and other STEP search tools are retrieval aids. They are not final authority unless the selected candidate has traceable supplier/manufacturer identity and evidence.

## Candidate Record

For each credible candidate, record:

- part id and category;
- supplier or manufacturer;
- SKU or manufacturer part number;
- source URL and datasheet URL;
- STEP/STP URL or cached path;
- access/license notes;
- key dimensions and interface metadata;
- rating evidence relevant to the requirement;
- geometry match status;
- engineering rating status;
- ranking rationale and rejected alternatives.

Required selected-part fields must satisfy the Zen CAD schema before final PASS.

## Source-Lock Rules

A part is source-locked only when:

- `status` is `source_locked`;
- `completion_eligible` is true;
- supplier/manufacturer and SKU/part number are present;
- source URL is present;
- cached STEP/STP path exists when caching is allowed;
- key dimensions match the requirement or mismatch is explicitly accepted;
- ratings needed for final claims are backed by datasheet, standard, calculation, or test evidence;
- proxy flags are false for final evidence.

Run:

```bash
./zen-cad source-lock milestones/<id>
```

before treating sourced parts as final.

## Geometry vs Rating

STEP geometry proves geometry only. It does not prove:

- material;
- load rating;
- electrical rating;
- fatigue life;
- bearing life;
- certification;
- supplier authenticity;
- manufacturing readiness.

Use `geometry_match` for CAD/interface fit and `engineering_rating_verified` for datasheet/rating evidence. Keep these separate.

## Normalized STEP Metadata

When the harness has CAD inspection tooling, create or update `02_parts/normalized_step_metadata.json` with:

- file path, size, and SHA-256;
- units and bounding box;
- major axes, datums, refs, and mating features;
- origin/frame assumptions;
- loadability result and command metadata when available;
- limitations.

If inspection is not available, record the blocker. Do not fabricate dimensions from a screenshot.

## Fallback and Blockers

If no credible candidate is found:

1. Record attempted queries and sources in `01_research/research_log.md`.
2. Try alternate standards, manufacturer names, regional terms, and dimensional families.
3. Search approved internal libraries or prior milestone caches.
4. If still unavailable, create a proxy only for concept/layout work.
5. Mark `replacement_required_before_final: true`.
6. Do not allow `/spec-to-cad` to generate a final lookalike unless the engineering decision changes to a custom-manufactured substitute.

## Final Response Contract

Report:

- selected candidate IDs and source URLs;
- cached STEP/STP paths;
- datasheet/rating evidence status;
- rejected alternatives and why;
- `./zen-cad source-lock` result;
- unresolved source-lock blockers and smallest unblock steps.
